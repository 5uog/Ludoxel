## プロジェクト概要

Ludoxel（以下「本アプリケーション」という。）は、小西拳斗が公開又は配布するデスクトップアプリケーションである。Ludoxel ドキュメントサイト（以下「本ドキュメントサイト」という。）は、本アプリケーションに関する説明、法務表示、利用案内、技術文書、及び公開用 Web 表示を提供する文書サイトである。本リポジトリは、本アプリケーション及び本ドキュメントサイトに関するソースコード、文書、設定、ビルドスクリプト、検査ツール、シェーダー、資産、リソース、メタデータ、パッケージ関連ファイル、法務資料、ワークフロー関連ファイル、配布準備資料、Web サイト関連ファイル、及びその他のリポジトリ内容を含む。

本リポジトリには、本アプリケーションの独自素材、本ドキュメントサイトの独自素材、第三者素材、来歴確認を要する素材、実行時利用者データ、通常のアプリケーション出力、配布時資料、Web サイト配備資料、及びリポジトリ方針文書が混在し得る。これらは、技術的に同じリポジトリ内に存在し、同じ配布物に含まれ、同じ Web サイト上に表示され、又は同じ画面上に表示される場合であっても、法務上は同一の素材区分として扱われない。

本書は、ルートの [`LICENSE`](LICENSE)、本ドキュメントサイト、第三者素材のライセンス表示、来歴確認を要するローカル資産、実行時利用者データ、通常のアプリケーション出力、配布時法務資料、Web サイト配備物、ホスティングサービスの機能及び利用条件、並びに [`.github/`](.github/) 配下のリポジトリ方針文書の相互関係を示す入口文書である。本書は、利用許諾、保証、配布権限、Web サイト再利用権限、第三者素材の権利状態、又はホスティングサービス上の利用権限を設定しない。
